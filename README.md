# Senior Python Async CRM

This repository contains a full-featured, production-ready, senior-level backend for a multi-tenant, async CRM system. It is based on the specification in `Testovoe-zadanie-Senior-Python.docx`.

## Tech Stack
- Python 3.10+
- FastAPI (async)
- SQLAlchemy Core (async)
- Alembic (migrations)
- PostgreSQL (RDBMS)
- JWT (access/refresh tokens)
- Type hints, mypy/pyright
- Docker + Docker Compose
- pydantic-settings
- Structured: api, services, repositories, models

## Features
- Organization/user multi-tenant CRM, async backend
- Fully type-annotated + linted
- RESTful JSON API (v1)
- Clean, scalable architecture with in-memory and DB layers
- Comprehensive tests and documentation
